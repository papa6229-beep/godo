# 여름 해변 신제품 이벤트 페이지 디자인 사양

날짜: 2026-08-04
상태: 사용자 레이아웃 선택 완료 — A 수평선 중심형

## 1. 목적과 산출물

- Canva에서 다시 수정할 수 있는 세로형 이벤트 페이지 1개를 만든다.
- 최종 크기는 정확히 **840 × 1498px**이다.
- 여름 해변, 맑은 하늘과 바다, 청량한 블루·화이트 중심의 분위기를 낸다.
- 텍스트와 여섯 원본 이미지는 각각 편집 가능한 Canva 요소로 유지한다.
- 결과물은 Canva 편집 링크로 전달한다.

## 2. 선택한 시각 방향

선택안은 **A 수평선 중심형**이다. 하늘→바다→백사장으로 이어지는 세로 흐름을 만들고, 사용자의 시선이 상단 로고와 날짜에서 메인 할인 문구를 거쳐 세 제품으로 자연스럽게 내려가게 한다.

- 상단: 맑은 하늘과 짙은 블루 영역. 흰색인 1번 원본이 선명하게 보이는 배경이다.
- 중단: 밝은 시안 블루 바다와 수평선. 할인 문구의 가독성을 확보한다.
- 하단: 흰 파도와 밝은 모래 영역. 검은 제품 세 개의 윤곽이 분명하게 드러난다.
- 최하단: 다시 짙은 블루 띠를 두어 흰색인 6번 원본을 원형 그대로 보여준다.

## 3. 고정 문구

아래 문구는 철자·띄어쓰기·기호를 한 글자도 바꾸지 않는다.

- 메인 문구: `신제품 20% OFF 출시기념`
- 보조 문구 1: `08.01 ~ 08.31`
- 보조 문구 2: `가장 먼저 만나는 새로운 경험! 장인의 손으로 한땀한땀 빚어낸`

시각적 줄바꿈은 허용하지만 문자 내용과 순서는 바꾸지 않는다.

## 4. 요소 배치

1. **1번 이미지**: 중앙 상단. 원본 비율을 유지하고, 흰색 요소가 보이도록 짙은 블루 하늘 영역에 놓는다.
2. **2번 이미지**: 페이지 우측 최상단. 원본 비율·색상·글자를 유지한다.
3. **보조 문구 1**: 메인 문구 좌상단.
4. **메인 문구**: 상단 3분의 1 안에서 가장 큰 요소로 표시한다. `20% OFF`의 크기와 대비를 가장 강하게 하되 문구 자체는 그대로 유지한다.
5. **보조 문구 2**: 메인 문구 바로 아래. 제품과 겹치지 않는 독립 텍스트 영역에 둔다.
6. **3·4·5번 이미지**: 보조 문구 2 아래의 하단 제품 무대에 배치한다. 4번을 중앙 주인공으로 세우고, 3번은 왼쪽, 5번은 오른쪽에 둔다. 모든 제품은 원본 비율을 유지하며 문구와 겹치지 않는다.
7. **6번 이미지**: 디자인 최하단 중앙. 짙은 블루 하단 띠 위에 원본 그대로 둔다.

## 5. 색상과 서체

- 배경 핵심색: 딥 블루 `#075B9A`, 오션 블루 `#0EA5D8`, 스카이 블루 `#70D8F5`, 화이트 `#FFFFFF`, 샌드 `#F5EBD4`.
- 메인 문구는 화이트를 기본으로 하고 `20% OFF`만 선명한 선샤인 옐로 계열로 강조한다.
- 보조 문구는 화이트 또는 짙은 블루 중 배경 대비가 높은 색을 사용한다.
- 한글은 굵고 현대적인 산세리프 계열을 사용한다. 메인·보조 문구는 각각 별도 텍스트 레이어로 둔다.

## 6. 원본 보존 규칙

- `1.png`부터 `6.png`까지 사용자가 제공한 파일만 제품·로고 요소로 사용한다.
- 자르기, 왜곡, 재색상, 재생성, 글자 수정, 로고 재작성은 하지 않는다.
- 허용되는 조정은 비율을 유지한 확대·축소와 위치 변경뿐이다.
- 배경과 장식 요소는 원본 이미지 뒤에만 놓는다.

## 7. Canva 제작 흐름

1. 여섯 원본을 Canva 자산으로 각각 업로드한다.
2. A 수평선 중심형을 기준으로 Canva 포스터 초안을 만든다.
3. 디자인을 **840 × 1498px**로 맞춘다.
4. 텍스트 3종을 정확한 원문으로 교정하고 각각 편집 가능한 레이어로 유지한다.
5. 여섯 원본을 지정 위치에 배치하고 원본 비율을 확인한다.
6. 1페이지 미리보기에서 가독성·겹침·배치·문자 정확성을 검사한다.
7. 사용자에게 최종 미리보기를 보여주고 저장 승인을 받은 뒤 Canva 디자인을 확정한다.

## 8. 실패·예외 처리

- 원본 업로드가 실패하면 해당 이미지를 임의로 대체하지 않고 업로드를 다시 시도한다.
- Canva 자동 생성이 문구를 바꾸거나 원본을 변형하면 초안을 그대로 확정하지 않고 편집 단계에서 원문과 원본 자산으로 교체한다.
- 정확한 위치 조정이 제한되는 요소는 겹치지 않는 범위에서 가장 가까운 위치로 두되, 지정된 상하 순서는 바꾸지 않는다.
- 미리보기에서 1번 또는 6번이 보이지 않으면 원본은 수정하지 않고 뒤의 블루 배경 대비만 조정한다.

## 9. 완료 검사

- 캔버스가 840 × 1498px이다.
- 페이지는 1개다.
- 세 문구가 원문과 완전히 일치한다.
- 1번은 중앙 상단, 2번은 우측 최상단, 3·4·5번은 보조 문구 2 아래, 6번은 최하단이다.
- 제품은 문구와 겹치지 않는다.
- 여섯 원본의 비율·색상·내부 글자가 유지된다.
- 텍스트와 이미지가 Canva에서 다시 선택·수정 가능한 요소다.
- 최종 미리보기와 Canva 편집 링크를 사용자에게 제공한다.
